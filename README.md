
# Hello OSS

## 1. Giới thiệu dự án
Hello OSS là một dự án phần mềm mã nguồn mở đơn giản được viết bằng ngôn ngữ C. Chương trình có chức năng hiển thị dòng chữ "Hello OSS" trên màn hình.

## 2. Mục tiêu dự án
- Làm quen với quy trình phát triển phần mềm mã nguồn mở.
- Thực hành sử dụng Git và GitHub.
- Tìm hiểu cách xây dựng tài liệu README và CONTRIBUTING.
- Tìm hiểu cách lựa chọn giấy phép mã nguồn mở.

## 3. Yêu cầu hệ thống
- Hệ điều hành Windows.
- Trình biên dịch GCC.
- Command Prompt (CMD).

## 4. Hướng dẫn biên dịch
Mở CMD tại thư mục dự án và nhập:

```cmd
gcc main.c -o hello-oss.exe
```

## 5. Hướng dẫn chạy chương trình
Sau khi biên dịch thành công, nhập:

```cmd
hello-oss.exe
```

Kết quả hiển thị:

```text
Hello OSS
```

## 6. Hướng dẫn đóng góp
Người dùng có thể tham gia đóng góp cho dự án thông qua Issues và Pull Requests trên GitHub.

Xem chi tiết trong file CONTRIBUTING.md.

## 7. Giấy phép
